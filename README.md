# Long Context Orchestrator

A Codex skill for tasks that may span multiple context windows. It helps coordinate independent work, keep evidence tied to its sources, and resume an interrupted task.

## Install

Create `$HOME/.agents/skills/long-context-orchestrator/` and copy both [SKILL.md](SKILL.md) and the [references/](references/) directory into it. Keep the directory structure so the skill can load its references.
