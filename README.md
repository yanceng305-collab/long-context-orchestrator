# Long Context Orchestrator

An early dogfooding Codex Skill for reducing information loss in long-context tasks. It coordinates subagents, durable Markdown memory, and staged synthesis so large research and analysis work can survive context compaction.

## Install

Copy `SKILL.md` to:

```text
$HOME/.agents/skills/long-context-orchestrator/SKILL.md
```

This is a V1 intended for real-world dogfooding and will evolve based on actual usage.
